# 🐟 メダカ管理帳

メダカの餌やり・水換え・添加剤・日誌・台帳を管理するPWAアプリです。

## デプロイ手順

### 1. GitHubにアップロード

1. [github.com](https://github.com) にログイン
2. 右上の「＋」→「New repository」をクリック
3. Repository name に `medaka-app` と入力
4. 「Create repository」をクリック
5. このフォルダをそのままアップロード（「uploading an existing file」リンクをクリック）

### 2. Vercelにデプロイ

1. [vercel.com](https://vercel.com) にアクセスしてGitHubアカウントでログイン
2. 「Add New → Project」をクリック
3. `medaka-app` リポジトリを選択して「Import」
4. 設定はデフォルトのまま「Deploy」をクリック
5. 数分でデプロイ完了 → URLが発行される

### 3. iPhoneのホーム画面に追加

1. iPhoneのSafariで発行されたURLを開く
2. 下部の共有ボタン（□↑）をタップ
3. 「ホーム画面に追加」をタップ
4. 「追加」をタップ

これでホーム画面にアイコンが追加され、アプリとして起動できます。

## 機能

- 🏠 ホーム：餌やり・水換え・PSB・ビタミン剤の管理
- 📅 記録：カレンダーでケア記録を確認
- 📝 日誌：水槽ごとの観察記録
- 🐠 台帳：メダカの入荷記録
- 👥 フレンド：IDでフレンドと日誌を共有
